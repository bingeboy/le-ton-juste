# McIntosh MC100 Power Amplifier

## Specifications

| Parameter | Value |
|---|---|
| Type | Solid state mono block |
| Production | 1970–1974 |
| Power Output | 100W RMS @ 8Ω (tested up to 145W before clipping) |
| THD | <0.25% at rated power |
| Input Impedance | ~100kΩ (unbalanced RCA) |
| Input Sensitivity | ~0.75V for rated output |
| Input Connector | RCA unbalanced |
| Output Taps | 2Ω, 4Ω, 8Ω, 16Ω (barrier strip / screw terminals) |
| Output Stage | Direct-coupled → McIntosh Autoformer |
| Weight | ~40 lbs |

## Architecture

The MC100 is early McIntosh solid state — transistors feeding their patented **Autoformer** (unity-coupled output transformer). The Autoformer provides:
- Identical power output into any load impedance
- Consistent frequency response regardless of speaker impedance variation
- Stable damping factor across all loads
- DC protection for speakers

This is NOT a tube amp. It's a solid-state hi-fi amplifier from McIntosh's transition era. The sound is described by audiophiles as "closer to tube warmth" compared to later McIntosh solid state models.

## Jerry Garcia Context

Jerry used the **MC2300** (the big brother — 300W/ch, bridgeable to 600W mono), not the MC100. However, the architecture and philosophy are identical:
- Same Autoformer output design
- Same solid-state, high-headroom approach
- Same "transparent amplification" philosophy

The MC100 is essentially a home/small-venue version of Jerry's MC2300. For a 2x12 JBL rig, 100W of clean McIntosh power is more than adequate.

## Why Solid State McIntosh Works for This Tone

1. **Massive headroom.** 100W into efficient JBL E120s (103dB sensitivity) means zero power amp clipping at any practical volume.
2. **No coloration.** Unlike a tube power amp (Marshall, Fender, Vox) that adds compression, sag, and harmonic distortion, the McIntosh amplifies cleanly. All tone comes from the preamp and pedals.
3. **Autoformer stability.** Speaker impedance varies with frequency. The autoformer ensures the amp's frequency response stays flat regardless.
4. **"Hi-fi" approach.** This rig treats the guitar as a full-range instrument and amplifies it like a PA — the anti-thesis of traditional guitar amp overdrive.

## Current Speaker Configuration

- 2x JBL E120-8 in parallel = **4Ω load**
- Use the MC100's **4Ω output tap**
- Autoformer ensures full 100W delivery into this load
