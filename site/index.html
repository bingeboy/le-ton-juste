Design

Ghost Spring Tank

One spring. One voice. Transformer-coupled for the organic bloom that no direct-drive circuit can replicate — the same mechanism that made the Fender 6G15 Reverb Unit sound like nothing else.

Spring TankAccutronics 9AB3C1B — Long, 3-spring, long decay, 8Ω input / 2550Ω output
Driver XfmrAccutronics REB3S — dedicated spring reverb driver, 8Ω secondary
Driver StageBD139 NPN transistor → REB3S → tank. Class A, ~19mA quiescent
Op-AmpsOPA2134PA throughout — input buffer, recovery preamp, output buffer
Signal Path100% analog. Post-recovery 300Hz HPF on wet signal only
ControlsDwell (10kΩ lin) · Mix (100kΩ audio + 47pF bright cap) · Tone (100kΩ audio)
PowerInternal ±15V linear — toroidal 15VA, LM7815/LM7915. IEC mains inlet
Form Factor2U aluminum rackmount. Rack ears included with chassis
Tank MountHorizontal, open-side down, 4× Shore 30A rubber isolation grommets

Why Transformer Coupling

The transformer's inductance forms a resonant circuit with the spring's input impedance, creating a slight peak at ~2–3kHz on the attack transient — the "drip" character of the Fender 6G15. Also provides galvanic isolation between the driver stage and tank.

Signal Flow

Line In
  → Input Buffer   OPA2134 · 1MΩ input · unity gain
  → Dwell Pot      10kΩ linear · spring drive level
  → BD139 Driver   Class A · ~19mA · into REB3S primary
  → REB3S Xfmr    8Ω secondary → tank input
  → 9AB3C1B Tank  3 springs · long decay
  → Recovery       OPA2134 · 214× gain (~46dB)
  → 300Hz HPF      Wet signal only · C4 100nF + R6 5.6kΩ
  → Tone Pot       High-shelf EQ · wet only
  → Mix Pot        100kΩ audio · 47pF bright cap
  → Output Buffer  OPA2134 · <100Ω output · to MC100
